How to declare figure links

Add repro-manifest.json next to the project README. Paths are relative to that folder.

{
  "version": 1,
  "figures": [{
    "figure": "figures/fig1.svg",
    "data": "data/example.csv",
    "script": "scripts/plot.py"
  }]
}
